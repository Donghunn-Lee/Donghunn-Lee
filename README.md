## ✨ About

> 상호작용이 많은 UI에서<br/>
> “**상태는 어디서 바뀌고, 렌더링은 누가 책임지는가**”를 기준으로 설계합니다.

- 사용자 입력과 화면 반응이 밀접하게 연결되는 환경에서  
  상태와 렌더링의 책임을 명확히 분리하는 데 관심이 있습니다.
- 단순히 빠르게 동작하는 것보다,  
  **예측 가능하고 설명 가능한 구조**를 만드는 것을 중요하게 생각합니다.
- 프로젝트에서는 기능 구현보다  
  구조 선택의 근거와 변경 시 영향 범위를 먼저 고민합니다.
